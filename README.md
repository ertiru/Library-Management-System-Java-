# Library Management System (Java)

A simple object-oriented Library Management System developed in Java as a practice project for learning core OOP concepts and data structures.

## Features

* Add new books to the library
* Prevent duplicate books based on ISBN
* Search books by title
* Check whether a book already exists
* Display all fictitious books
* Find the newest published book
* Delete books from the library
* Store books using arrays (without Java Collections)

## Concepts Demonstrated

* Object-Oriented Programming (OOP)
* Classes and Objects
* Encapsulation
* Constructors
* Arrays
* Method overriding (`toString()` and `equals()`)
* Object comparison
* Array manipulation (searching, inserting, deleting)

## Technologies

* Java
* IntelliJ IDEA / Eclipse / VS Code (compatible)

## Project Structure

* `Book.java` – Represents a book with its ISBN, title, publication year, and category.
* `Library.java` – Manages the collection of books and provides operations such as adding, deleting, searching, and retrieving books.

## Purpose

This project was created as a learning exercise to strengthen Java programming fundamentals and practice implementing object-oriented design without relying on Java Collection classes such as `ArrayList`.
